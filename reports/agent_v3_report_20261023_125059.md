### AI инженер болох 7 хоногийн эрчимжүүлсэн сургалтын төлөвлөгөө

*Тэмдэглэл: Локал файл дахь мэдээлэл хязгаарлагдмал байгаа тул AI инженерчлэлийн суурь практик туршлагад тулгуурлан уг төлөвлөгөөг боловсруулав.*

---

#### 1 дэх өдөр: Python суурь ба Өгөгдлийн бүтэц (Lists, Dictionaries)
* **Зорилго:** AI инженерчлэлд зайлшгүй шаардлагатай Python хэлний үндсэн өгөгдлийн бүтцийг эзэмших.
* **Дасгал:** Жагсаалт (List), толь бичиг (Dictionary), болон функц ашиглан хэрэглэгчийн өгөгдлийг боловсруулах энгийн скрипт бичих.
* **Үр Дүн:** Python код амжилттай ажиллаж, өгөгдлийг шүүж, утга буцаадаг болно.

#### 2 дахь өдөр: Python код цэгцлэх ба Асинхрон программчлал (Async/Await)
* **Зорилго:** API хүсэлт болон агентуудад хэрэгтэй asynchronous (асинхрон) үйлдлийн үндсийг ойлгох.
* **Дасгал:** `async` ба `await` түлхүүр үгсийг ашиглан олон зэрэгцсэн хуурамч (mock) хүсэлт илгээх туршилт хийх.
* **Үр Дүн:** Кодын гүйцэтгэлийг түргэсгэх асинхрон функцийн бүтцийг ойлгож, туршиж үзсэн байна.

#### 3 дахь өдөр: REST API болон HTTP хүсэлтүүд
* **Зорилго:** Вэб үйлчилгээтэй холбогдох, өгөгдөл солилцох чадвартай болох.
* **Дасгал:** Python-ийн `requests` эсвэл `httpx` номын санг ашиглан үнэгүй公开 API-аас (жишээ нь: цаг агаар эсвэл хошин шогийн API) мэдээлэл татаж авах.
* **Үр Дүн:** API-аас JSON форматтай өгөгдөл амжилттай татаж авч, хэрэгтэй утгыг нь ялгаж авч чаддаг болно.

#### 4 дэх өдөр: OpenAI эсвэл LLM API-тай холбогдох
* **Зорилго:** Том хэлний загварын (LLM) API-г Python код руу холбож сурах.
* **Дасгал:** LLM API түлхүүр (API Key) ашиглан энгийн мессеж илгээж, хариу авах скрипт бичих.
* **Үр Дүн:** Код дамжуулан хиймэл оюун ухаанаас хариу авч чадах үндсэн холболт үүснэ.

#### 5 дахь өдөр: Prompt Engineering (Промпт инженерчлэл)
* **Зорилго:** LLM-ээс хүссэн үр дүнгээ үнэн зөв гаргуулахын тулд зааварчилгаа (Prompt) бичих арга барилд суралцах.
* **Дасгал:** Системийн рол (System Prompt), хэрэглэгчийн рол ашиглан тодорхой нэг үүрэг гүйцэтгэх (жишээ нь: орчуулагч эсвэл код шалгагч) промпт зохиож турших.
* **Үр Дүн:** Загварын гаралтын чанар сайжирч, тогтвортой хариу авах аргад суралцана.

#### 6 дахь өдөр: AI Agent-ийн суурь ойлголт ба Tool Calling (Багаж ашиглах)
* **Зорилго:** AI agent хэрхэн шийдвэр гаргаж, гадаад функц/багаж ашигладагийг ойлгох.
* **Дасгал:** LLM-д өөрийн бичсэн энгийн Python функцийг (жишээ нь: тооны машин эсвэл вэб хайлтын функц) "багаж" болгон холбож өгөх.
* **Үр Дүн:** AI нь хэрэглэгчийн асуултаас хамааран тохирох функцийг дуудаж ажиллуулах анхны агентын логик үүснэ.

#### 7 дахь өдөр: Мини AI Agent төсөл бүтээх
* **Зорилго:** Сурсан мэдлэгээ нэгтгэн энгийн бие даасан AI agent хийж турших.
* **Дасгал:** Хэрэглэгчээс асуулт аваад, шаардлагатай бол API-аас мэдээлэл татаж авч хариулдаг мини агентын скрипт бичиж дуусгах.
* **Үр Дүн:** Python, API, LLM болон Agent-ийн үндсэн холболтыг багтаасан ажилладаг жижиг хэмжээний төслөтэй болно.
