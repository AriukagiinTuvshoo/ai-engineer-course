AI инженерчлэлийн тэмдэглэл

1. Python бол AI систем хөгжүүлэхэд өргөн ашиглагддаг программчлалын хэл.
2. API нь программ болон бусад үйлчилгээний хооронд мэдээлэл солилцох боломж олгодог.
3. LLM нь текст ойлгож, хариулт үүсгэдэг хэлний загвар.
4. Function calling нь AI-д Python функц болон бусад хэрэгслийг ашиглах боломж олгодог.
5. SQLite нь өгөгдлийг файл хэлбэрээр хадгалдаг өгөгдлийн сан.
6. Найдвартай AI системд эрхийн хязгаарлалт, алдаа шалгалт, тест хэрэгтэй.
